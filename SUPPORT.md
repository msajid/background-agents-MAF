## Get help

Use GitHub Issues when you can provide:

* The command you ran
* Python, uv, Azure CLI, and package versions
* The complete error message with credentials removed
* Your operating system
* Minimal reproduction steps

For Microsoft Agent Framework product questions, use the support channels linked from the
[official repository](https://github.com/microsoft/agent-framework).

## Scope

Repository maintainers can help with this example's setup, code, and documentation. They
cannot provide Azure subscription support, guarantee travel recommendations, or troubleshoot
unrelated applications built from the sample.

Report suspected vulnerabilities privately by following [SECURITY.md](./SECURITY.md).
